# Governance

Rules controlling documentation authority, status, provenance, and change control for the TCIndustries project.

Contains or will contain:

- the authority/provenance reconciliation matrix, including the adopted governance rules GR-001–GR-004 and GR-006 (detective and corrective control of project decisions — filing obligations, dependent-document consistency, and the rule that a filing defect never voids a ruling);
- status and status-discipline definitions;
- document author/assessor attribution requirements (GR-004);
- human decision records (HD-*) and decision gates;
- change-control and elevation (promotion) procedures.

Note: **GR-005** (filename convention compliance) is recorded as owner-confirmed in
`proposals/TCIndustries_Manifest.md` but has never been merged into the matrix and
is **not in force** there. Merging it is a separate owner act.

Governance material defines *how documents become authoritative* — it does not itself authorise game design.

See `AGENTS.md` at the repository root for the operating rules every agent must follow.
