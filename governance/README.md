# Governance

Rules controlling documentation authority, status, provenance, and change control for the TCIndustries project.

Contains or will contain:

- the authority/provenance reconciliation matrix;
- status and status-discipline definitions;
- human decision records (HD-*) and decision gates;
- change-control and elevation (promotion) procedures.

Governance material defines *how documents become authoritative* — it does not itself authorise game design.

See `AGENTS.md` at the repository root for the operating rules every agent must follow.
