SWG Historical Accuracy — Human Recollection Questionnaire

Star Wars Galaxies Pre-CU recollection instrument. v1.0 — Answers are EVIDENCE only, never canon.

Answering rules

  • Answer from recollection only. If unsure, write TBD / I don't remember / unknown — never guess a number.
  • Distinguish "I remember it worked like X" (recollection) from "I think it was probably X" (inference). Mark inference explicitly.
  • Numbers are recollected magnitudes only — never tuning targets.
  • If you never used a system, mark N/A — never used.
